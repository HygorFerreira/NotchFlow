# Renovação visual das novas funções

Prévias reais de SwiftUI, geradas com dados fictícios em português. O player usa uma faixa de demonstração; nenhuma biblioteca musical foi consultada. O mixer aparece desativado, sem capturar áudio.

- Navegação do notch com ícones, título da aba ativa e ação lateral sem sobreposição.
- Player com capa, hierarquia de faixa/artista, reprodução destacada e painel de letras.
- Ferramentas com navegação própria, editor de notas, seleção, datas e contador de caracteres.
- Clipboard com busca, contador, estados vazios e confirmação de cópia.
- Arquivos com área de arraste demarcada; mixer com controles e estados orientativos.
- Paleta com busca destacada, quantidade de resultados e seleção por teclado.
